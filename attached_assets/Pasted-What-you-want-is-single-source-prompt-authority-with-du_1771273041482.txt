# 🧠 The Core Principle

Do **not** store prompts inside AutoHotkey.

Instead:

> The PWA is the source of truth.
> AutoHotkey is just a runtime executor.

AHK should dynamically read from a generated config file.

---

# 🏗️ Clean Architecture

Here’s the ideal structure:

```
Cloudflare Worker
    ↓
KV / D1 / Durable Object
    ↓
PWA (Prompt Editor UI)
    ↓
Prompt JSON Registry
    ↓
Export Generator (AHK format)
    ↓
Local Sync Script
    ↓
AutoHotkey Dynamic Loader
```

# 🔥 Step 1 — Store Prompts in Structured JSON

In your PWA database:

```json
{
  "id": "adv_review",
  "title": "Adversarial Review",
  "shortcut": "Ctrl+Alt+A",
  "category": "TQD",
  "prompt": "You are a hostile peer reviewer...",
  "temperature": 0.2,
  "model": "gpt-4.1"
}
```

Everything lives in one registry.

---

# 🔥 Step 2 — Export Generator Endpoint

Your Cloudflare worker should generate:

```
GET /export/ahk
```

It returns:

```ahk
; AUTO-GENERATED FILE - DO NOT EDIT

^!a::
RunPrompt("adv_review")
return

^!s::
RunPrompt("support_review")
return
```

It dynamically maps:

* Shortcut → Prompt ID

No prompt text stored in AHK.

Just ID references.

---

# 🔥 Step 3 — AutoHotkey Loader

Your AHK script should include:

```ahk
#Include prompt_registry.ahk

RunPrompt(id) {
    Clipboard := ""
    Send ^c
    ClipWait, 1
    
    text := Clipboard
    SendToPWA(id, text)
}
```

Then:

```
SendToPWA(id, text)
```

Just POSTs to:

```
https://clipboard-sync.davidokc28.workers.dev/run
```

With:

```json
{
  "prompt_id": "adv_review",
  "content": "clipboard text"
}
```

Now PWA handles:

* Model selection
* Prompt text
* OpenAI call
* Logging
* Storage

AHK is dumb and clean.

---

# 🔥 Step 4 — Auto Sync Script

Write a small Python script:

```python
import requests

url = "https://your-worker/export/ahk"
r = requests.get(url)

with open("prompt_registry.ahk", "w") as f:
    f.write(r.text)
```

Run this:

* On startup
* On clipboard action
* Or on hotkey reload

Now every time you update shortcuts in the PWA…

AutoHotkey updates automatically.

# ⚠️ Important Design Rule

Never let AHK contain real prompt text.

Always store prompts server-side.

This gives you:

* Version control
* Audit logs
* History
* Security
* Model switching without AHK changes
